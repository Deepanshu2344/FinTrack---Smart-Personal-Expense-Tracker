FinTrack is a smart personal finance management system built using HTML/CSS, PHP, JavaScript, and SQL. It helps users track expenses, set budgets, manage recurring costs, and stay informed through email alerts. Whether you're budgeting for a week or a year, FinTrack simplifies money management for individuals.

🚀 Features
🔐 Secure User Authentication
- Signup/Login with email verification
- Password reset via email
- Login notification email for security

💰 Expense Management
- Add, edit, and delete daily expenses
- Track by weekly, monthly, and yearly timelines
- Supports recurring expenses

📈 Budget Planning
- Create and manage category-wise budgets
- Alerts for budget overflow
- View budget vs expense analysis

📊 Insightful Dashboard
- Dynamic charts using Chart.js

📧 Email Notifications
- Login alerts to verify it’s you
- Budget overflow alerts
- Reminders for recurring expenses (1 day before)

💬 Support Form
- Easy-to-use contact/help page

🛠️ Tech Stack
- Layer	Technologies Used
- Frontend	HTML5, CSS3, JavaScript
- Backend	PHP (core), AJAX for interactions
- Database	MySQL
- Charts	Chart.js
- Notifications	PHPMailer / Sendmail (for email alerts)
